# 잔상 별자리 Android APK 설계

## 목표

현재의 한영 별자리 운세 PWA를 Android에서 브라우저 주소창 없이 실행되는 독립 앱으로 패키징한다. 웹 버전의 계산, 상세 풀이, 그래프, 언어 저장과 오프라인 자산을 그대로 유지한다.

## 앱 정체성

- 앱 이름: `잔상 별자리`
- 패키지 ID: `com.jansang.star`
- 웹 소스와 동일한 GPL-3.0-or-later 라이선스를 유지한다.
- 기존 잔상 별자리 아이콘과 크림·브라스 색감을 Android 실행 화면과 앱 아이콘에 사용한다.

## 패키징 방식

- Capacitor Android 셸을 사용한다.
- Android 프로젝트는 저장소의 `android/` 아래에 두어 이후에도 다시 빌드할 수 있게 한다.
- Capacitor의 `webDir`은 Vite 산출물인 `dist`를 사용한다.
- Android 빌드는 루트 경로(`/`) 자산을 사용하고, GitHub Pages 빌드는 기존 `/jansang-star/` 경로를 계속 사용한다.
- 앱은 원격 웹사이트를 단순히 여는 방식이 아니라 빌드된 웹 자산을 APK 안에 포함한다.

## 기능과 권한

- 출생정보 입력, Swiss Ephemeris 계산, 오늘·이번 달·올해 운세, 그래프와 한영 전환을 유지한다.
- 프로필과 언어 설정은 기존 로컬 저장 방식을 유지한다.
- 카메라, 연락처, 위치 등 불필요한 Android 권한은 추가하지 않는다.
- 외부 서버로 개인정보를 전송하지 않는 현재 동작을 유지한다.

## 빌드 산출물

- 로컬 설치가 가능한 디버그 서명 APK를 생성한다.
- 최종 파일은 `outputs/jansang-star-android-debug.apk`로 복사한다.
- Android 프로젝트와 재빌드 명령을 README에 기록한다.
- 정식 스토어 배포용 개인 서명키는 이번 범위에 포함하지 않는다.

## 검증

- 웹 전체 테스트와 TypeScript/Vite 빌드를 통과해야 한다.
- Capacitor 동기화와 Gradle APK 조립을 오류 없이 완료해야 한다.
- APK 파일 존재, 크기, ZIP 무결성, 패키지 ID와 앱 이름을 확인한다.
- 가능한 경우 Android 에뮬레이터 또는 연결 기기에서 설치·실행하여 첫 화면과 핵심 입력 흐름을 확인한다.
- 웹 GitHub Pages 배포가 기존 PWA, 서비스워커와 자산 경로를 유지하는지 별도로 확인한다.
