# 잔상 별자리 Celestial Atelier·한영 전환·상세 풀이 설계

## 목표

잔상 별자리를 조용하고 편집적인 고급 점성술 서비스로 재설계한다. 기존 천체 계산과 데이터 저장 방식은 유지하면서 시각 체계를 `Celestial Atelier`로 전환하고, 한국어와 영어 전체 UI 및 해석을 제공하며, 출생 차트부터 일간·월간·연간 운세까지 근거가 드러나는 장문 리포트로 확장한다.

완성 기준은 다음과 같다.

- 한국어 브라우저는 한국어, 그 외 브라우저는 영어로 처음 열린다.
- 사용자는 상단 `한 / EN` 버튼으로 즉시 언어를 바꾸며 선택은 같은 기기에 저장된다.
- 언어를 바꿔도 입력값, 출생 차트, 선택한 운세 기간과 스크롤 맥락이 유지된다.
- 한국어 리포트는 전체 기준 약 4,000~7,000자 수준이며 영어도 같은 정보 밀도를 제공한다.
- 해석은 출생 행성, 하우스, 애스펙트와 트랜짓을 근거로 하며 같은 입력과 날짜에는 같은 결과가 나온다.
- 모바일 390px과 데스크톱 1440px에서 읽기 쉬우며 공개 GitHub Pages 주소에서 계산이 성공한다.

## 범위와 비범위

### 포함

- 랜딩, 입력, 로딩, 오류, 결과, 법적 고지의 Celestial Atelier 시각 개편
- 전체 UI·접근성 명칭·점성술 용어의 한국어 및 영어 제공
- 한국어 브라우저 감지, 수동 언어 선택과 영구 저장
- 핵심 성향, 10행성, 12하우스, 주요 애스펙트, 트랜짓, 분야별 운세, 월간 및 연간 운세의 장문화
- 차트와 기간 그래프의 색상·선 위계·범례 개편
- 모바일 및 데스크톱 실제 브라우저 검증
- GitHub Pages 재배포와 PWA 캐시 갱신 검증

### 제외

- 서버, 로그인, 결제, 외부 AI API
- 영어 이외의 제3 언어
- 천체 계산 체계 변경: 열대황도, 플라시두스, Swiss Ephemeris는 유지
- 사용자가 입력한 이름의 번역 또는 변형

## 시각 체계: Celestial Atelier

### 색상

기본 배경은 따뜻한 본 아이보리 `#F3EFE7`, 중심 대비면은 옵시디언 `#11100E`를 사용한다. 주 강조색은 샴페인 브라스 `#B79A62`, 보조 금속색은 페일 브라스 `#D2C29F`로 제한한다. 본문 잉크는 `#24211D`, 어두운 면의 본문은 웜 아이보리 `#F4F0E8`를 사용한다. 보조 정보는 웜 그레이 `#777168`, 조화 애스펙트는 딥 코발트 `#385A78`, 긴장 애스펙트는 코퍼 레드 `#9C5544`를 사용한다.

보라색·핑크 네온은 제거한다. 금색은 활성 탭, 핵심 점수, 선택된 행성, 중요한 구분선과 CTA에만 사용한다. 넓은 면을 금색으로 채우지 않는다.

### 표면과 위계

- 랜딩과 입력 화면은 본 아이보리 기반의 편집 지면처럼 구성한다.
- 출생 차트와 핵심 운세는 옵시디언 패널로 대비시킨다.
- 긴 리포트는 아이보리와 옵시디언 장을 교차시켜 독서 리듬을 만든다.
- 기존의 둥근 유리 카드 반복을 줄이고, 1px 미만의 섬세한 구분선과 넉넉한 여백을 기본으로 한다.
- 큰 표면은 20~28px, 작은 데이터 셀은 10~16px의 절제된 곡률을 사용한다.
- 그림자는 검은 확산 그림자와 얇은 상단 반사광만 사용하며 유색 발광은 차트의 선택 상태로 제한한다.

### 타이포그래피

제목에는 웹 안전성을 고려한 고대비 세리프 스택을 사용하고, 본문·숫자·컨트롤에는 시스템 산세리프를 사용한다. 대형 제목은 음수 자간과 짧은 행간, 본문은 1.7~1.9 행간을 적용한다. 영어 제목은 Title Case, UI 레이블은 sentence case로 통일한다. 한국어 본문은 과도하게 얇은 굵기를 사용하지 않는다.

### 차트와 그래프

출생 차트는 옵시디언 천문 관측판 위에 웜 아이보리 외곽선, 브라스 주요 축, 딥 코발트 조화각, 코퍼 레드 긴장각을 사용한다. 행성 노드는 금속 메달처럼 외곽·코어·미세 반사광의 세 층으로 표현한다. 긴장각은 점선 패턴을 유지해 색상만으로 의미를 전달하지 않는다.

월간·연간 그래프는 굵은 보라색 막대 대신 가는 브라스 선과 점, 약한 면적 음영을 사용한다. 최고·주의 구간은 아이콘과 문구를 함께 제공한다.

## 국제화

### 언어 결정 순서

1. 저장된 사용자 선택 `jansang-language`가 있으면 사용한다.
2. 없으면 `navigator.languages`와 `navigator.language`에서 첫 한국어 계열(`ko`, `ko-KR`)을 찾는다.
3. 한국어 계열이면 `ko`, 나머지는 `en`을 사용한다.

이 규칙은 국가 IP가 아니라 브라우저 언어를 사용한다. 위치 권한이나 외부 요청 없이 개인정보를 보호하면서 국가별 기본 언어 기대를 충족한다.

### 수동 전환

상단 내비게이션에 `한 / EN` 세그먼트를 둔다. 현재 언어는 브라스 배경과 명확한 선택 상태로 표시한다. 전환 시 페이지를 다시 계산하거나 초기화하지 않고 React 컨텍스트의 locale만 변경한다. `document.documentElement.lang`도 함께 갱신한다.

### 번역 구조

- `i18n` 모듈은 locale 감지, 저장, 컨텍스트와 공통 번역 함수를 담당한다.
- 정적 UI 문구는 키 기반 `ko`·`en` 사전에 둔다.
- 별자리, 행성, 하우스, 애스펙트 용어는 언어별 도메인 사전에 둔다.
- 운세와 상세 풀이 템플릿은 한국어·영어를 독립 작성한다. 한국어 문장을 런타임 기계 번역하지 않는다.
- 날짜와 숫자는 `Intl.DateTimeFormat`과 `Intl.NumberFormat`으로 현재 locale에 맞춘다.
- 사용자 이름과 입력값은 번역하지 않는다.

## 상세 풀이 엔진

### 공통 원칙

각 해석 단위는 `근거 → 성향 또는 체감 → 강점/기회 → 그림자/주의 → 실천` 순서를 따른다. 문구는 결정론적으로 선택하며, 사용된 행성·별자리·하우스·애스펙트·오브를 근거 칩으로 노출한다. 점성술을 단정적 예언이나 의료·투자 조언으로 표현하지 않는다.

해석 데이터는 언어 중립적인 의미 토큰으로 먼저 만든다. 예: `tone: supportive`, `theme: communication`, `evidence: transitMercuryTrineNatalMoon`. 한국어와 영어 렌더러가 같은 의미 토큰을 각 언어 문장으로 구성하므로 두 언어의 점수와 결론이 달라지지 않는다.

### 핵심 성향

- 태양, 달, 상승궁 각각 4~6문장
- 별자리 위치와 하우스를 함께 해석
- 정체성, 감정적 안전, 첫인상, 강점, 과잉 표현, 성장 행동 포함
- 출생시간 미상일 때 상승궁 해석을 생성하지 않고 제한 이유를 안내

### 10행성

행성마다 3~5문장을 제공한다. 행성의 기능, 별자리식 표현, 하우스의 실제 생활 영역, 순행·역행의 체감, 활용 행동을 포함한다. 행성 카드의 요약과 확장 본문을 분리해 전체 화면이 한꺼번에 장문으로 보이지 않게 한다.

### 12하우스

하우스마다 2~4문장으로 삶의 영역, 커스프 별자리의 접근 방식, 해당 하우스에 위치한 행성의 영향을 설명한다. 행성이 없는 하우스도 '비어 있어 중요하지 않다'고 표현하지 않고 커스프 별자리와 주제 중심으로 해석한다.

### 주요 애스펙트

가장 정확한 6~10개를 우선 표시한다. 각 애스펙트는 3~5문장으로 두 행성의 욕구, 조화 또는 긴장, 반복되는 생활 패턴, 통합 방법을 제공한다. 오브가 좁을수록 시각적 선과 설명 우선순위가 강해진다.

### 오늘

- 종합운 6~8문장
- 연애·재물·직업·건강 각각 4~6문장
- 가장 강한 트랜짓 1~2개와 오브 표시
- 오전/오후 흐름, 기회, 주의, 구체적 행동 포함
- 같은 출생 차트와 날짜는 같은 결과

### 이번 달

현재처럼 월의 1일, 8일, 15일, 22일, 말일 정오 표본을 사용한다. 전체 6~8문장, 분야별 전략 3~5문장, 다섯 구간별 2~3문장, 가장 강한 기회 구간과 주의 구간을 제공한다. 날짜는 해당 locale 형식으로 표시한다.

### 올해

매월 15일 정오의 12개 표본을 사용한다. 전체 8~10문장, 4개 분기별 3~4문장, 12개월별 2~3문장, 전환점·확장기·정리기를 제공한다. 가장 높은 달 하나만 강조하지 않고 반복되는 주제와 분기 간 흐름을 설명한다.

## 정보 구조와 상호작용

결과 화면 상단은 출생 차트, 이름, 핵심 메시지, 언어 전환을 유지한다. 그 아래 `오늘 / 이번 달 / 올해` 세그먼트가 현재 기간을 제어한다. 상세 출생 리포트는 기간과 무관한 별도의 장으로 유지한다.

긴 글은 다음 원칙으로 관리한다.

- 각 장 상단에 1~2문장 요약을 먼저 제공한다.
- 핵심 성향과 오늘의 종합운은 기본 펼침 상태다.
- 10행성, 12하우스, 애스펙트, 월별 세부 내용은 접근 가능한 아코디언으로 확장한다.
- 사용자가 언어를 바꿔도 열어둔 아코디언과 선택 기간을 보존한다.
- 모든 터치 대상은 최소 44px이며 키보드와 스크린 리더를 지원한다.

## 오류와 예외

- 번역 키가 누락되면 개발 환경에서 명확히 실패하고 테스트가 누락 키를 보고한다.
- 운영 환경의 방어적 폴백은 영어가 아니라 현재 locale의 안전한 일반 문구를 사용한다.
- 출생시간 미상, 하우스 계산 불가, 트랜짓 표본 실패는 해당 장에 구체적인 제한 이유를 표시하며 다른 장은 계속 제공한다.
- 저장된 locale 값이 `ko` 또는 `en`이 아니면 자동 감지를 다시 수행한다.

## 배포

기존 `jansang18/jansang-star` 저장소의 `main`과 `gh-pages` 배포 방식을 유지한다. 빌드 자원 경로는 `/jansang-star/`를 유지하고 Swiss Ephemeris의 `wasm` 및 `data` 파일을 회귀 테스트로 보장한다. 새 서비스 워커는 이전 캐시를 제거하고 즉시 활성화되어 색상·언어 사전·상세 풀이가 구버전 캐시에 가려지지 않게 한다.
