# 전 세계 도시 검색과 파스텔 입력 선택 상태

## 목표

영어판에서도 한국 도시만 먼저 보이는 문제를 해소하고, 웹과 APK에서 국가·도시·시간대를 포함한 전 세계 주요 도시를 오프라인으로 검색할 수 있게 한다. 입력칸을 선택하면 검은 박스 대신 부드러운 파스텔 배경으로 상태를 전달한다.

## 전 세계 도시 데이터

- GeoNames의 전 세계 주요 도시 데이터 중 인구 15,000명 이상 도시와 행정 중심지를 빌드 시 정제해 정적 검색 데이터로 포함한다.
- 각 항목은 안정적인 ID, 도시 표시명, ASCII 이름, 필요한 검색 별칭, 국가 코드, 위도, 경도, IANA 시간대를 가진다.
- 기존 한국어 도시명과 주요 해외 도시의 한국어 별칭은 우선 보존한다.
- 국가명은 `Intl.DisplayNames`로 한국어 또는 영어에 맞게 표시하고, 지원되지 않는 환경에서는 국가 코드를 사용한다.
- 원본 데이터 출처와 라이선스 고지를 저장소와 앱에 포함한다.

## 검색 경험

- 도시 입력에 포커스하면 언어에 맞는 대표 도시를 한국에 편중되지 않게 보여준다.
- 글자를 입력하면 도시명, ASCII 이름, 한국어·영어 별칭, 국가명과 시간대를 대상으로 검색한다.
- 결과는 관련도, 완전 일치, 접두어 일치, 인구 규모 순으로 정렬하고 한 번에 최대 20개를 보여준다.
- 각 결과는 `도시 · 국가`와 `IANA 시간대`를 함께 표시한다.
- 데이터는 도시 검색을 처음 사용할 때 지연 로드하며, 로딩·결과 없음·데이터 로드 실패 상태를 한영으로 안내한다.
- 선택한 도시의 위도·경도·시간대를 기존 출생 차트 계산 흐름에 그대로 전달한다.
- 목록에 없는 장소는 기존 위도·경도·시간대 직접입력으로 처리한다.

## 파스텔 선택 상태

- 입력 컨테이너의 기본 모서리는 14px, 최소 높이는 52px로 통일한다.
- 아이콘, 텍스트, 날짜와 시간 값은 세로 중앙에 정렬한다.
- 포커스된 입력 컨테이너는 옅은 블루그레이 파스텔 배경으로 전환한다.
- 검은 외곽선은 제거하고 중간 회색 테두리와 반투명 외곽 링으로 키보드 포커스를 구분한다.
- 포커스 해제 시 부드럽고 짧게 원래 크림 배경으로 돌아오며, `prefers-reduced-motion`에서는 전환 효과를 제거한다.
- 계산 버튼, 상단 CTA와 결과 기간 탭의 기존 고대비 포커스는 변경하지 않는다.

## 오프라인과 배포

- 도시 데이터는 GitHub Pages PWA와 Capacitor APK 양쪽에 포함한다.
- 서비스워커가 도시 데이터와 천문 계산 자산을 오프라인에서 사용할 수 있게 캐시한다.
- GitHub Pages의 `/jansang-star/` 경로와 Android의 `/` 경로를 각각 유지한다.
- 개인정보와 검색어를 외부 도시 API로 전송하지 않는다.

## 검증

- 빈 검색 목록에서 여러 국가의 도시가 함께 노출되는지 확인한다.
- 한국어·영어·ASCII 도시명, 국가명과 시간대 검색을 각각 검증한다.
- 서울, 도쿄, 뉴욕, 런던 등 대표 도시 선택 시 좌표와 시간대가 정확히 전달되는지 검증한다.
- 입력 포커스의 파스텔 배경, 14px 라운드, 52px 높이와 세로 중앙 정렬을 회귀 테스트로 고정한다.
- 모바일·데스크톱에서 검색 성능, 키보드 조작, 가로 넘침과 포커스 가시성을 확인한다.
- 웹 전체 테스트, Pages 빌드, 공개 배포 및 APK 빌드·설치 검증을 수행한다.
