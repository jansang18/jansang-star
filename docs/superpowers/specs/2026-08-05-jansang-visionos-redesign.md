# 잔상 별자리 visionOS 재디자인 및 배포 설계

## 목표

기존 ‘잔상 별자리’의 천체 계산과 결과 구조는 보존하면서 화면을 Apple식 visionOS 공간 디자인으로 재구성한다. 결과 화면 상단과 모든 섹션의 가로폭을 하나의 정렬축에 맞추고, 출생 차트를 대표 그래픽으로 강화하며, 짧은 일일 운세를 근거와 행동 조언이 포함된 장문 운세로 확장한다. 완성본은 독립 공개 저장소 `jansang18/jansang-star`에 복제해 GitHub Pages로 배포한다.

## 성공 기준

- 데스크톱의 내비게이션, 히어로, 결과 섹션, 푸터가 모두 동일한 최대 1120px 레일에 정렬된다.
- 모바일에서는 모든 주요 화면이 동일한 좌우 16px 여백을 사용한다.
- 깊은 우주 배경, 공간형 유리 재질, 발광 차트와 잔상 그래픽이 visionOS 계열의 깊이감을 만든다.
- 종합운은 5~7문장, 연애·재물·직업·건강운은 각각 3~5문장으로 제공한다.
- 기존 출생정보 입력, 열대황도·플라시두스 계산, SVG 차트, 저장, PWA 기능이 유지된다.
- 공개 주소 `https://jansang18.github.io/jansang-star/`에서 직접 접속과 새로고침이 모두 작동한다.

## 시각 설계

### 공간과 정렬

앱 전체에 `--content-rail: 1120px`와 `--page-gutter: clamp(16px, 4vw, 40px)`를 정의한다. 내비게이션, 입력 패널, 결과 히어로, 모든 결과 카드와 푸터는 공통 `.content-rail` 규칙을 사용한다. 내부 정보 밀도에 따라 그리드 열 수만 바꾸고 외곽 폭은 바꾸지 않는다.

### 배경

- 기본 배경은 청흑색에서 보랏빛으로 이어지는 깊은 우주색이다.
- 화면 가장자리에 저채도 파랑·보라·마젠타 광원을 배치한다.
- 별점은 작은 정적 점과 느린 잔상 궤적으로 분리한다.
- 큰 배경은 위치를 계속 움직이지 않고, opacity와 transform만 사용하는 짧은 진입 효과만 둔다.

### 재질 계층

- 내비게이션: 얇고 밝은 상단 유리 재질. 스크롤 콘텐츠와 분리하되 하드 디바이더는 사용하지 않는다.
- 히어로 차트: 가장 두꺼운 공간 재질. 강한 배경 블러, 밝은 상단 테두리, 깊은 그림자를 사용한다.
- 일반 결과 섹션: 중간 두께 재질. 불투명도를 높여 본문 가독성을 우선한다.
- 작은 행성·하우스 항목: 별도의 유리를 중첩하지 않고 단색 반투명 표면을 사용한다.
- 유리 위에 다시 밝은 유리를 중첩하지 않아 명암이 흐려지는 문제를 방지한다.

### 색과 타이포그래피

- 시스템 글꼴 스택을 유지하고 `font-optical-sizing: auto`를 적용한다.
- 큰 제목은 크기별 음수 자간과 촘촘한 행간을 사용한다.
- 작은 레이블은 약한 양수 자간과 높은 대비를 사용한다.
- 본문은 흰색에 가까운 고대비 색, 보조 문장은 푸른 회색을 사용한다.
- 핵심 색은 전기 파랑, 라벤더, 마젠타로 제한한다.

## 출생 차트 그래픽

SVG 구조와 실제 계산 데이터는 유지하고 표현 레이어를 강화한다.

- 바깥 황도 링에 이중 발광과 미세한 광택을 추가한다.
- 12별자리 영역은 얇은 방사형 그라데이션으로 구분한다.
- 행성은 작은 발광 구체와 글리프를 결합한다.
- 조화 애스펙트는 파랑·청록, 긴장 애스펙트는 코랄·마젠타로 표시한다.
- 선의 오브 강도에 따라 투명도와 굵기를 함께 조절한다.
- ASC와 MC는 일반 하우스 선보다 굵고 밝게 표시한다.
- 중앙 별은 여러 광원 잔상이 겹친 것처럼 보이되 텍스트를 방해하지 않는다.
- 원형 차트와 동일한 정보를 읽을 수 있는 표를 계속 제공한다.

### 선 굵기와 가독성 기준

- 황도 바깥 링의 실제 중심선은 2.25px, 보조 링은 1.25px로 표시한다.
- 일반 하우스 커스프는 0.9px, ASC·MC 축은 2px로 표시해 계층을 구분한다.
- 애스펙트 실제 중심선은 오브 정확도에 따라 0.75~1.75px 범위에서 조절한다.
- 발광은 실제 선을 흐리는 blur가 아니라 동일 경로 아래에 별도 복제한 3~8px 반투명 레이어로 만든다.
- 행성 노드는 데스크톱 32~36px, 모바일 최소 28px의 시각 크기를 확보한다.
- 글리프는 발광과 분리된 불투명 전경에 놓아 작은 화면에서도 형태가 번지지 않게 한다.
- 조화·긴장 애스펙트는 색상뿐 아니라 실선·점선 패턴과 기호로도 구분한다.
- 차트 주변에 애스펙트 범례와 현재 선택된 행성의 이름·각도·하우스를 표시한다.
- 배경과 실제 차트 중심선의 명암비는 최소 3:1, 텍스트는 WCAG AA를 충족한다.
- 모바일에서는 차트 자체를 축소만 하지 않고 외곽 레이블 간격과 행성 노드 충돌을 다시 계산한다.
- 텍스트와 실제 중심선에는 CSS blur를 적용하지 않는다. blur는 장식용 복제 레이어에만 허용한다.

## 상호작용과 모션

- 버튼은 pointer-down에 즉시 `scale(0.97)` 반응을 보인다.
- hover는 이동보다 빛과 재질 두께 변화로 표현한다.
- 결과 섹션은 처음 보일 때 짧은 materialize 효과를 사용한다. opacity, scale, blur가 함께 안정된다.
- 사용자가 조작하는 동안 입력을 잠그지 않는다.
- `prefers-reduced-motion`에서는 이동과 스케일을 제거하고 짧은 opacity 변화만 유지한다.
- `prefers-reduced-transparency`에서는 배경 불투명도를 높이고 블러를 제거한다.
- `prefers-contrast: more`에서는 카드 테두리와 본문 대비를 높인다.

## 장문 운세 설계

유료 AI를 사용하지 않고 기존 결정론적 규칙 엔진을 확장한다. 동일 차트와 날짜는 항상 동일한 문장을 반환한다.

### 출력 구조

- 종합운: 핵심 천체 신호, 전체 분위기, 기회, 긴장 요소, 우선 행동, 피해야 할 행동을 5~7문장으로 설명한다.
- 연애운: 감정·금성·화성 관련 신호, 관계에서의 체감, 대화 조언을 3~5문장으로 설명한다.
- 재물운: 금성·목성·토성 관련 신호, 지출·계약·자원 관리 조언을 3~5문장으로 설명한다.
- 직업운: 태양·수성·화성·목성·토성 관련 신호, 협업·집중·결정 조언을 3~5문장으로 설명한다.
- 건강운: 태양·달·화성·토성 관련 신호, 에너지 리듬과 생활 조언을 3~5문장으로 설명한다.

### 생성 방식

1. 분야별 트랜짓 애스펙트를 정확도와 행성 가중치로 정렬한다.
2. 가장 강한 도움 신호와 긴장 신호를 각각 하나 이상 선택한다.
3. 근거, 체감, 기회, 주의, 행동 템플릿을 분야별로 조합한다.
4. 날짜와 출생 차트 해시로 동점 템플릿을 결정한다.
5. 같은 의미의 문장이 연속되지 않도록 문장 역할을 기준으로 중복을 제거한다.
6. 단정적 예언과 의료·법률·투자 확정 표현은 사용하지 않는다.

## 컴포넌트 변경

- `tokens.css`: 공간 색상, 재질, 공통 레일과 접근성 토큰
- `global.css`: 공통 정렬축, 우주 배경, 버튼 피드백, 입력 화면 재질
- `results.css`: 결과 전체 폭 통일, visionOS 카드 계층, 반응형 규칙
- `NatalChart.css`와 `NatalChart.tsx`: 발광 링, 행성 구체, 애스펙트 강도 표현
- `copy.ko.ts`: 문장 역할별 한국어 템플릿
- `generateFortune.ts`: 장문 섹션 조합과 중복 방지
- 결과 컴포넌트: 장문 문단과 천체 근거 라벨 표시

## 데이터 흐름

`출생정보 → 기존 천체 계산 → 출생 차트 → 오늘의 트랜짓 → 분야별 강한 신호 정렬 → 장문 문장 역할 조합 → 공통 1120px 결과 레일 렌더링 → 기기 내 저장`

천체 계산 데이터와 개인정보 처리 방식은 변경하지 않는다.

## 오류 처리

- 천체 계산 실패 시 기존 재시도 가능한 오류 화면을 유지한다.
- 특정 분야에 유효한 트랜짓이 적으면 출생 차트 성향과 일반적인 현지 날짜 흐름으로 보충하고 근거를 조작하지 않는다.
- 템플릿 키가 누락되면 빈 영역 대신 검수된 중립 문장을 표시한다.
- GitHub Pages 배포가 실패하면 Actions 로그를 확인하고 성공한 기존 배포는 유지한다.

## 테스트와 검증

- 기존 17개 테스트를 모두 유지한다.
- 동일 날짜·차트의 장문 운세 결정성 테스트를 추가한다.
- 각 분야의 최소 문장 수와 점수 범위 테스트를 추가한다.
- 1120px 공통 레일과 모바일 16px 여백을 실제 브라우저에서 확인한다.
- 390px 모바일과 1440px 데스크톱 전체 화면을 캡처해 정렬과 잘림을 검토한다.
- reduced motion, reduced transparency, 높은 대비 미디어 쿼리를 확인한다.
- GitHub Pages에서 첫 접속, 직접 경로, 새로고침, WASM 로딩, PWA manifest를 검증한다.

## 독립 GitHub Pages 배포

- 새 공개 저장소: `jansang18/jansang-star`
- 저장소는 현재 작업 프로젝트와 독립된 원격 저장소로 사용한다.
- Vite의 `base`를 `/jansang-star/`로 설정한다.
- GitHub Actions가 `npm ci`, 테스트, 빌드 후 `dist`를 Pages 아티팩트로 배포한다.
- Pages 소스는 GitHub Actions로 설정한다.
- 공개 주소는 `https://jansang18.github.io/jansang-star/`로 고정한다.
- 저장소에는 소스, 테스트, 디자인 문서, README와 라이선스 안내를 포함한다.

## 완료 기준

- 모든 주요 카드의 양쪽 끝이 동일한 레일에 맞는다.
- visionOS 계열의 깊이, 재질, 발광 그래픽이 데스크톱과 모바일에서 일관된다.
- 모든 운세 영역이 정해진 최소 문장 수를 충족하며 같은 입력에 같은 결과를 낸다.
- 기존 계산과 접근성 테스트가 회귀하지 않는다.
- GitHub Actions가 성공하고 공개 URL에서 실제 출생 차트가 계산된다.
