# 잔상 별자리 웹앱 설계

## 1. 목표

‘잔상 별자리’는 생년월일, 정확한 출생시간, 출생지역을 입력하면 서양 현대 점성술 기준의 출생 차트와 오늘의 운세를 한 페이지에 길게 펼쳐 보여주는 모바일 우선 웹앱이다. 사용자는 만세력 결과표를 읽듯 차트, 핵심 별자리, 행성, 하우스, 애스펙트, 오늘의 트랜짓과 분야별 운세를 위에서 아래로 훑을 수 있어야 한다.

성공 기준은 다음과 같다.

- 휴대폰과 PC에서 모두 사용하며 휴대폰에는 PWA로 설치할 수 있다.
- 동일한 입력에는 항상 동일한 출생 차트가 나온다.
- 출생지역의 좌표와 역사적 시간대를 반영해 천체 위치와 하우스를 계산한다.
- 생일만으로 태양궁을 보여주는 간이 운세가 아니라 출생시간과 장소가 필요한 정통 출생 차트를 제공한다.
- 첫 결과 화면에서 핵심 내용을 이해할 수 있고, 아래로 내리면 전문적인 근거까지 확인할 수 있다.
- 매일의 문구는 유료 AI 호출 없이 규칙과 검수된 문장 조각으로 생성한다.

## 2. 범위

### 포함

- 이름 또는 별칭, 생년월일, 출생시간, 출생지역 입력
- 지역 자동완성과 위치 후보 선택
- 열대황도와 플라시두스 하우스 체계
- 태양, 달, 수성, 금성, 화성, 목성, 토성, 천왕성, 해왕성, 명왕성의 위치
- 상승점(ASC), 중천점(MC), 12하우스 커스프
- 합, 충, 삼분, 사각, 육분의 주요 애스펙트
- 태양궁, 달궁, 상승궁 요약
- 행성별 별자리와 하우스 해석
- 주요 애스펙트 해석
- 출생 차트와 오늘의 트랜짓을 비교한 일일 운세
- 종합, 연애, 재물, 직업, 건강 운세 및 행운색, 숫자, 시간, 오늘의 조언
- SVG 기반 원형 출생 차트와 잔상 모션 그래픽
- 입력과 최근 결과의 기기 내 저장
- PWA 설치와 기본 오프라인 재열람

### 제외

- 회원가입, 유료 결제, 상담사 연결, 커뮤니티
- AI API를 이용한 자유 대화나 문장 생성
- 두 사람의 궁합, 월간·연간 운세, 택일
- 인도 점성술, 항성황도, 홀사인 등 계산 체계 전환
- 의료, 법률, 투자 판단을 대신하는 조언

## 3. 사용자 흐름

1. 첫 화면에서 ‘나의 별자리 만세력 보기’를 선택한다.
2. 이름 또는 별칭, 생년월일, 출생시간, 출생지역을 입력한다.
3. 출생지역 후보에서 실제 도시를 선택한다. 앱은 위도, 경도, IANA 시간대 식별자를 함께 확정한다.
4. 입력값 검증 후 출생 시각을 UTC로 변환하고 차트를 계산한다.
5. 결과 상단에서 원형 차트, 태양궁·달궁·상승궁, 오늘의 종합운을 확인한다.
6. 아래로 스크롤하며 행성 배치, 12하우스, 주요 애스펙트, 오늘의 트랜짓, 분야별 운세와 행운 정보를 읽는다.
7. 입력값은 사용자의 기기에만 저장되며 다음 방문 시 오늘 날짜 기준 운세가 다시 계산된다.

출생시간을 모르는 경우에는 시간을 임의로 추정하지 않는다. 상승궁과 하우스가 정확하지 않다는 안내를 보여주고, 사용자가 계속 진행하면 행성의 별자리 중심으로 제한된 결과만 제공한다.

## 4. 화면과 시각 체계

### 브랜드

- 이름: **잔상 별자리**
- 한 줄 설명: **태어난 순간의 별빛은 오늘도 잔상을 남깁니다.**
- 인상: 밝고 현대적이며 신비롭되, 어둡거나 무거운 점술 화면은 피한다.
- 배경: 하늘색, 라벤더, 연한 살구색이 겹치는 밝은 그라데이션
- 포인트: 선명한 보라색과 푸른색
- 그래픽 모티프: 별이 이동하며 남기는 흐린 빛의 궤적, 겹쳐진 별점, 투명한 유리 카드

### 결과 페이지 순서

1. 브랜드 헤더와 오늘 날짜
2. 사용자 이름, 출생정보, 원형 출생 차트
3. 태양궁·달궁·상승궁 카드
4. 오늘의 코스믹 웨더 점수와 한 줄 요약
5. 행성 배치표
6. 12하우스 요약
7. 주요 애스펙트와 강도
8. 오늘의 주요 트랜짓
9. 종합·연애·재물·직업·건강 운세
10. 행운색·숫자·시간·오늘의 조언
11. 계산 기준, 책임 제한, 입력 수정 버튼

### 모션과 접근성

- 잔상은 장식 레이어로만 사용하고 텍스트 위를 지나지 않는다.
- 첫 진입에서 별점과 궤적이 0.8~1.2초 동안 부드럽게 나타난다.
- 스크롤 시 카드는 짧게 페이드인하지만 필수 정보는 애니메이션 없이도 보인다.
- `prefers-reduced-motion`이 활성화되면 모든 잔상 이동과 스크롤 모션을 정지한다.
- 본문과 배경은 WCAG AA 수준 명암비를 확보하고 색상만으로 점수나 애스펙트를 구분하지 않는다.
- 원형 차트에는 같은 내용을 읽을 수 있는 표와 텍스트 설명을 함께 제공한다.

## 5. 기술 구조

### 프런트엔드

- React와 TypeScript 기반 단일 페이지 PWA
- 반응형 레이아웃과 재사용 가능한 카드 컴포넌트
- 출생 차트는 확대해도 선명한 SVG로 렌더링
- 잔상 그래픽은 CSS와 SVG 필터로 구현하며 필수 기능과 분리
- 입력값과 최근 계산 결과는 브라우저 저장소에 보관

### 계산 계층

계산 코드는 화면과 분리된 점성술 엔진으로 둔다. 엔진의 입력은 UTC 출생시각, 위도, 경도이고 출력은 행성 황경, 별자리, 하우스, ASC, MC, 애스펙트의 구조화 데이터다.

- 황도 체계: 열대황도
- 하우스 체계: 플라시두스
- 주요 애스펙트: 0°, 60°, 90°, 120°, 180°
- 오브는 행성 종류와 애스펙트별 설정표에서 관리한다.
- 일일 트랜짓은 사용자가 결과를 보는 지역의 현지 날짜 정오를 기준으로 계산해 하루 동안 결과가 흔들리지 않게 한다.
- 천문 계산 라이브러리는 어댑터 뒤에 두어 라이선스 또는 정확도 요구로 교체해도 화면과 해석 규칙이 영향을 받지 않게 한다.

사용하는 천문 계산 구현은 개발 단계에서 기준 차트 표본과 대조해 확정한다. 무료 배포를 유지하기 위해 폐쇄 소스 상용 라이선스가 필요한 구현은 채택하지 않으며, 선택한 라이브러리의 오픈소스 라이선스 고지와 재배포 조건을 앱에 포함한다.

### 지역과 시간대

- 지역 검색은 앱에 포함된 도시 데이터에서 이름, 위도, 경도, IANA 시간대를 조회한다.
- 과거의 일광절약시간과 표준시 변화는 IANA 시간대 데이터로 변환한다.
- 동명이인 도시는 국가와 행정구역을 함께 표시한다.
- 목록에 없는 장소는 위도, 경도와 시간대를 직접 입력할 수 있는 고급 입력을 제공한다.

### 해석 엔진

유료 AI 대신 구조화된 규칙과 검수된 한국어 문장 조각을 사용한다.

1. 출생 차트에서 태양·달·상승궁, 행성의 별자리와 하우스, 주요 애스펙트를 추출한다.
2. 오늘의 트랜짓과 출생 차트 사이 애스펙트를 계산한다.
3. 영향 영역, 강도, 적용·분리 여부에 따라 규칙 점수를 매긴다.
4. 분야별 상위 신호를 선택하되 상충하는 신호는 우선순위 규칙으로 합친다.
5. 같은 날짜와 같은 차트에는 같은 문장과 점수를 반환한다.

점수는 0~100의 절대적 예언이 아니라 오늘의 흐름을 쉽게 비교하기 위한 시각 지표다. 화면에 이 의미를 짧게 안내한다. 문장 데이터는 계산 규칙과 분리된 파일로 관리해 점성술 검수와 문구 수정을 쉽게 한다.

## 6. 주요 컴포넌트

- `BirthInput`: 개인정보 입력, 지역 자동완성, 유효성 검사
- `LocationResolver`: 도시 후보와 좌표·시간대 확정
- `AstrologyEngine`: 천체 위치, 하우스, 애스펙트 계산
- `TransitEngine`: 오늘의 트랜짓과 출생 차트 비교
- `InterpretationEngine`: 규칙 점수화와 한국어 문장 조합
- `NatalChart`: SVG 원형 차트와 접근 가능한 대체 표
- `BigThreeSummary`: 태양궁·달궁·상승궁 요약
- `CosmicWeather`: 오늘의 점수, 핵심 신호, 한 줄 운세
- `PlacementSection`: 행성 배치와 해석
- `HouseSection`: 12하우스 배치와 해석
- `AspectSection`: 주요 애스펙트와 강도
- `DailyFortuneSection`: 종합·연애·재물·직업·건강 운세
- `LuckyGuide`: 행운색·숫자·시간·오늘의 조언
- `LocalProfileStore`: 기기 내 입력과 결과 저장

각 컴포넌트는 화면 표시만 담당하고, 계산 결과는 공통 데이터 모델을 통해 전달받는다. 계산 엔진은 UI에 의존하지 않아 단위 테스트와 교체가 가능해야 한다.

## 7. 데이터 흐름

`사용자 입력 → 지역·시간대 확정 → UTC 변환 → 출생 차트 계산 → 오늘의 트랜짓 계산 → 해석 규칙 적용 → 결과 데이터 생성 → SVG 차트와 세로형 카드 렌더링 → 기기 내 저장`

원시 입력과 계산 결과는 기본적으로 외부 서버로 전송하지 않는다. 정적 웹앱으로 배포하며 별도의 계정 서버나 데이터베이스를 두지 않는다.

## 8. 오류와 예외 처리

- 유효하지 않은 날짜나 존재하지 않는 현지 시각은 계산 전에 차단한다.
- 일광절약시간 전환으로 같은 시각이 두 번 존재하는 경우 사용자가 표준시 또는 일광절약시간을 선택하게 한다.
- 출생지역 후보가 여러 개면 국가와 행정구역을 표시해 다시 선택하게 한다.
- 출생시간 미상은 상승궁과 하우스를 생성하지 않고 제한 모드로 표시한다.
- 계산 실패 시 임의의 결과를 보여주지 않고 입력값과 실패 원인을 보존한 채 다시 시도할 수 있게 한다.
- 오프라인에서 도시 검색 데이터나 계산 자원이 준비되지 않았으면 필요한 항목을 명확히 안내한다.

## 9. 검증과 테스트

### 계산 정확도

- 서로 다른 시대, 반구, 시간대, 일광절약시간을 포함한 기준 출생 차트 표본을 준비한다.
- 행성 황경, ASC, MC, 하우스 커스프를 신뢰 가능한 기준 결과와 허용 오차 내에서 비교한다.
- 별자리 경계 0°와 30°, 날짜 변경선, 윤년, 자정 부근을 별도 회귀 테스트한다.
- 주요 애스펙트와 오브 경계값을 단위 테스트한다.

### 제품 동작

- 입력 → 계산 → 결과 → 재방문 흐름을 모바일과 데스크톱에서 종단 테스트한다.
- 저장된 출생 차트는 유지되고 오늘의 운세만 날짜가 바뀌면 갱신되는지 확인한다.
- 느린 기기에서도 잔상 그래픽이 입력과 스크롤을 방해하지 않는지 확인한다.
- 키보드 탐색, 스크린리더 레이블, 명암비, 모션 감소 설정을 점검한다.
- PWA 설치, 새로고침, 오프라인 재열람을 실제 브라우저에서 검증한다.

## 10. 책임과 표현 원칙

- 결과는 자기이해와 오락을 위한 해석임을 명시한다.
- 질병, 투자 수익, 법적 결과, 타인의 의사를 확정적으로 예언하지 않는다.
- ‘반드시’, ‘무조건’ 같은 단정 대신 가능성과 흐름을 설명한다.
- 계산 기준과 사용한 체계, 데이터 처리 방식을 사용자가 확인할 수 있게 공개한다.

## 11. 완료 기준

- 실제 출생정보로 계산한 차트가 기준 표본과 일치한다.
- 태양궁·달궁·상승궁과 행성·하우스·애스펙트가 한 페이지에 표시된다.
- 오늘의 트랜짓에서 파생된 다섯 분야 운세가 무료 규칙 엔진으로 생성된다.
- ‘잔상 별자리’의 밝은 파스텔, 고품질 SVG 차트, 잔상 모션이 모바일과 PC에서 자연스럽게 보인다.
- 출생정보가 외부로 전송되지 않고 기기에 저장된다.
- 설치 가능한 PWA이며 핵심 화면은 오프라인에서도 다시 열 수 있다.
