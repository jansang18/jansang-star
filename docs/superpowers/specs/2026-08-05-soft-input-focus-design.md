# 잔상 별자리 입력 박스 선택 상태 개선

## 목표

출생정보 입력칸을 선택했을 때 나타나는 검은 강조선을 현재의 크림·브라스 기반 화면과 어울리는 부드러운 연회색 강조선으로 바꾼다. 입력 박스의 둥근 모서리와 내부 세로 정렬도 통일한다.

## 디자인

- 입력 컨테이너의 기본 모서리를 14px로 통일한다.
- 입력 컨테이너는 동일한 최소 높이를 사용한다.
- 아이콘, 텍스트, 날짜와 시간 값은 컨테이너의 세로 중앙에 정렬한다.
- 포커스 시 검은 외곽 그림자를 제거하고 따뜻한 연회색 테두리와 은은한 외곽 링을 사용한다.
- 포커스 상태는 배경색을 과하게 채우지 않고 테두리와 미세한 그림자로만 전달한다.
- 생년월일과 출생시간 입력 박스는 같은 행에서 동일한 높이와 상단 기준선을 유지한다.

## 범위

- 이름, 생년월일, 출생시간, 출생지역 및 직접입력 좌표 필드에 적용한다.
- 계산 버튼, 상단 CTA, 결과 기간 탭의 기존 고대비 포커스 스타일은 변경하지 않는다.
- 입력값, 계산 로직, 번역, 그래프와 운세 콘텐츠는 변경하지 않는다.

## 접근성

- 실제 입력 요소의 포커스는 입력 컨테이너의 `:focus-within`으로 계속 표시한다.
- 키보드 사용자가 선택 위치를 알아볼 수 있도록 기본 테두리보다 명확한 연회색 링을 제공한다.
- 색상만이 아니라 테두리 두께와 외곽 링의 공간 차이로 상태를 구분한다.

## 검증

- 스타일 회귀 테스트에서 입력 포커스가 검정 `obsidian`을 사용하지 않는지 확인한다.
- 14px 라운드, 동일 높이, 내부 세로 중앙 정렬을 확인한다.
- 기존 버튼과 기간 탭의 고대비 포커스 테스트가 그대로 통과하는지 확인한다.
- 전체 테스트와 Pages 빌드를 실행한다.
- 모바일과 데스크톱에서 실제 입력 포커스, 박스 정렬, 가로 넘침을 확인한다.
